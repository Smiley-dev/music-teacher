# Exercise catalog

Exercises inspired by the music theory and ear training drills on
[ToneSavvy](https://tonesavvy.com/), reworked so the answer is **played on
the instrument** and judged by the app instead of clicked. Detection is
monophonic (ADR 0001), so anything with chords is played as an arpeggio.

Status: **done** (in the app), **idea** (fits the current engine), **later**
(needs a new capability), **no** (does not fit an instrument).

| Exercise (ToneSavvy) | On the instrument | Status |
| --- | --- | --- |
| Rhythm Performance | Play the rhythm shown, timing judged (Practice → Rhythm) | done |
| Note Names + Rhythm Performance together | **Reading**: sight-read a generated melody (scales, key signatures, intervals, note lengths); listen, then play it at your own pace or with the metronome (timing and pitch judged) | done |
| Note Names, Piano Keys, Guitar Frets, Violin/Viola/Cello/Double Bass Fingerboard | **Note reading**: a note appears on the staff, play it. One exercise with an instrument setting (clef, transposition, range) | done |
| Interval Building | **Intervals**: the first note is shown with an interval name (e.g. "Major 3rd up"); play both notes | done |
| Scale Building, Scales (ear) | **Scales**: play a named scale or mode from the root shown, up (and down); "Show the notes" turns it into scale reading | done |
| Chord Building, Chord Identification | **Chords**: play the notes of a named chord (triads, sevenths, inversions) bottom to top; "Show the notes" turns it into chord reading | done |
| Perfect Pitch, Intervals (ear), Melodic Dictation | **Ear training**: hear 1–8 notes (from a major key or chromatic), play them back | done |
| Paced Note Names | Note reading against the clock: notes scroll across the staff and must be played before they reach the end | idea |
| Interval Identification (theory) | Two notes shown on the staff: play both (Intervals with "Show both notes") | done |
| Key Signature Identification | A key signature is shown: play that major (or relative minor) scale | idea |
| Chord Functions | "V7 in G major": play the chord's notes as an arpeggio | idea |
| Intervals in Context, Scale Degrees (ear) | Hear a cadence that sets the key, then a note: play that note (or sing its degree) | later: needs chords in the reference playback (overlapping tones) |
| Chords (ear), Chord Progressions (ear) | Hear a chord or progression, play its root notes or arpeggios | later: needs chord playback |
| Rhythm Dictation | Hear a rhythm without notation, play it back (rhythm practice with the score hidden until the end) | idea |
| First Species Counterpoint | Write a counterpoint line | no (composition, not playing) |
